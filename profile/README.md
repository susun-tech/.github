<p align="center">
  <b><a href="https://github.com/susun-tech/susun">Susun</a></b> is a desktop database client for PostgreSQL, MySQL and SQLite.<br>
  SQL editor, table browser, JSON row viewer, ER diagrams and split panes, in one window.
</p>

_Susun_ (say _soo-soon_) is Malay for "to arrange" or "to stack": rows stacked in a grid, tabs
arranged into panes, and the three stacked rows of the logo.

Susun is open source under the MIT License and in active development. Installers aren't published
yet, so for now [build it from source](https://github.com/susun-tech/susun#development). Bug
reports and ideas are welcome in its [issues](https://github.com/susun-tech/susun/issues).
